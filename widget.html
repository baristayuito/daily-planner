ホーム画面に置く

アプリを開かなくても、今日やることがホーム画面に大きく出るようにします。最初の1回だけです。以後の更新は勝手に入ります。

  1. 1App Storeで Scriptable を入れる（無料）
  2. 2下の「コードをコピー」を押す
  3. 3Scriptableを開いて、右上の＋ → 貼り付け。名前を「デイリープランナー」にする
  4. 4下の▶を1回押す。設定コードを聞かれるので、アプリの設定タブでコピーした文字列を貼る
  5. 5ホーム画面を長押し → 左上の＋ → Scriptable → いちばん大きいサイズを置く
  6. 6置いたものを長押し →「ウィジェットを編集」→ Script で「デイリープランナー」を選ぶ
