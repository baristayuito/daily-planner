# デイリープランナー（画面だけ）

柿沼唯斗の個人用タスクアプリの**画面部分**です。ここには鍵もタスクの中身も入っていません。

- データはGoogle Apps Scriptのウェブアプリ（本人のGoogleアカウント上）に置いてあります
- 接続先のURLとAPIキーは、初回起動時に本人が入力し、その端末のブラウザ内にだけ保存されます
- iPhoneのSafariで開き「共有 → ホーム画面に追加」でアプリとして使えます

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面のすべて（HTML/CSS/JS） |
| `parser.js` | 「LP直し 40分 金曜まで」を項目に分解する |
| `sw.js` | 画面をキャッシュして素早く開く |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |

生成元は非公開リポジトリ側の `scripts/daily_planner/`（`build_web.py` で生成）。ここを直接編集しても元に戻ります。
